## Решения на Python

### Задача A

Файл: `e27_28766_A.py`

```python
from math import dist
from fnmatch import fnmatch

with open("27_A.txt") as f:
    p = [[float(x), float(y), v] for x, y, v in
         (s.replace(",", ".").split() for s in f)]

c = [
    [p for p in p if p[1] > 10],
    [p for p in p if p[1] <= 10]
]

centers = [
    min(cluster, key=lambda q: sum(dist(q[:2], p[:2]) for p in cluster))
    for cluster in c
]

d = [
    dist(centers[0][:2], p[:2])
     for p in p if fnmatch(p[2], "Y?III")
]

a1 = int(min(d) * 10000)
a2 = int(max(d) * 10000)

print(a1, a2)
```

**Краткое описание алгоритма:**

1. Считать координаты и идентификатор каждой точки из файла `27_A.txt`.
2. Разделить точки на два кластера: `y > 10` и `y <= 10`.
3. Для каждого кластера перебрать все его точки. Для очередной точки вычислить сумму расстояний до всех точек того же кластера.
4. Выбрать точку с минимальной суммой расстояний. Это медоид кластера.
5. Оставить точки, идентификаторы которых соответствуют маске `Y?III`.
6. Вычислить расстояния от медоида первого кластера до всех отобранных точек.
7. Найти минимальное и максимальное расстояния, умножить каждое на `10000` и вывести их целые части.

### Задача B

Файл: `e27_28766_B.py`

```python
from math import dist
from fnmatch import fnmatch

with open("27_B.txt") as f:
    p = [[float(x), float(y), v] for x, y, v in
         (s.replace(",", ".").split() for s in f)]

c = [
    [p for p in p if p[0] > 20],
    [p for p in p if p[0] <= 20 and p[1] > 22],
    [p for p in p if p[0] <= 20 and p[1] <= 22]
]

centers = [
    min(cluster, key=lambda q: sum(dist(q[:2], p[:2]) for p in cluster))
    for cluster in c
]

z = [
    [p[:2] for p in cluster if fnmatch(p[2], "Z?I")]
    for cluster in c
]

d = [
    dist(a, b)
    for cluster in z
    for a in cluster
    for b in cluster
    if a != b
]

b1=int(abs(min(d) * 10000))
b2=int(abs(dist(centers[0][:2], centers[2][:2]) * 10000))

print(b1, b2)
```

**Краткое описание алгоритма:**

1. Считать координаты и идентификатор каждой точки из файла `27_B.txt`.
2. Разделить точки на три кластера в порядке проверки условий:
   - первый: `x > 20`;
   - второй: `x <= 20` и `y > 22`;
   - третий: `x <= 20` и `y <= 22`.
3. Для каждого кластера найти медоид: перебрать его точки и выбрать ту, у которой сумма расстояний до остальных точек кластера минимальна.
4. В каждом кластере оставить только точки, идентификаторы которых соответствуют маске `Z?I`.
5. Перебрать все пары отобранных точек внутри каждого отдельного кластера и найти минимальное расстояние `B1`.
6. Найти расстояние `B2` между медоидами первого и третьего кластеров.
7. Умножить `B1` и `B2` на `10000`, взять абсолютное значение и вывести целую часть каждого результата.
